# OpenCode через GitHub

Workflow: .github/workflows/opencode.yml.

## Однократная активация
1. Settings → Secrets and variables → Actions → Variables: создайте OPENCODE_MODEL со значением provider/model (точный идентификатор доступной вам модели).
2. В Secrets добавьте соответствующий ключ: OPENAI_API_KEY для openai/*, ANTHROPIC_API_KEY для anthropic/* или OPENCODE_API_KEY для opencode/*.
3. Settings → Actions → General → Workflow permissions: разрешите GitHub Actions создавать pull requests.
4. Actions → OpenCode → Run workflow: оставьте check_only включенным. Проверка подтверждает наличие настроек, но не действительность ключа.
5. Для реальной задачи снимите check_only и укажите prompt либо оставьте комментарий от владельца репозитория: /opencode <задача>.

Выполнение использует API провайдера и может тарифицироваться отдельно от подписки ChatGPT. Не размещайте ключи в задачах, исходниках или чате.

## Ограничения запуска
Принимаются только новые комментарии владельца репозитория, начинающиеся с "/opencode ". Создание issue само по себе не запускает модель. Публикация workflow запускает только проверку конфигурации. Общедоступные ссылки на сессии отключены; таймаут задачи 20 минут. Автоматического слияния нет.

При постановке CAD-задачи укажите конкретную исходную версию, доступные файлы, требуемую правку и критерии проверки. Актуальные модели из чата должны быть отдельно перенесены в репозиторий: этот workflow их не переносит. Не возобновлять старый аудит по устаревшим issue без явного задания.

## Проверка результата
Проверяйте Actions и ответ/PR OpenCode. Успешная проверка наличия переменных не подтверждает успешное выполнение моделью. При использовании GITHUB_TOKEN действия, совершённые workflow, могут не запускать последующие workflows автоматически.

Официальная инструкция: https://opencode.ai/docs/github/
