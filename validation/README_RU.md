# Проверка сборки V4 (этапы 1–2)

Независимая перепроверка кандидата V4 из `handoff/current_assembly.tar.gz`
относительно принятой базы V3. Итог: **оба этапа пройдены** (`stage1_report.json`,
`stage2_report.json`), `passed: true`.

- Этап 1 — воспроизведение красного контура P07 из V3 и совпадение с переданным V4.
- Этап 2 — проверка сборки в 74 положениях: тела, оси, штифты, серая внутри жёлтой,
  жёсткая связь серой с P07, необходимость выреза P04; выпуск GIF и viewer.

## Команды

```bash
tar -xzf handoff/current_assembly.tar.gz
pip install -r validation/requirements.txt
python3 validation/stage1_reproduce_red_contour.py
python3 validation/stage2_verify_assembly.py
```

## Этап 1 — воспроизведение красного контура

`stage1_reproduce_red_contour.py` копирует принятую базу V3 в
`validation/work/reproduction/`, применяет `red_contour.py` и `contour_reference.png`
из V4 и проверяет результат (`stage1_report.json`):

- P07/P04 — валидные одиночные тела; симметрическая разность с V4 = 0,
  объём и габариты совпадают; обе детали отличаются от V3.
- Два сквозных отверстия P07 (r = 5.3, оси вдоль Z) сохранены: расхождение
  осей и радиусов = 0.
- Регистрация (`scale 1.9926005617`, `angle 3.1419913475`, `rms 0.561654 пикс`,
  256 точек контура) точно совпадает с `contour_change.json` V4.
- Остальные 7 деталей побайтово совпадают с V3.

## Этап 2 — 74 положения

`stage2_verify_assembly.py` берёт воспроизведение этапа 1 как кандидата,
запускает переданные скрипты V4 в отдельной папке и **независимо** перепроверяет
(`stage2_report.json`):

| Проверка | Результат |
| --- | --- |
| Пересечения тел (74 поз. × 36 пар) | 0, макс. объём = 0.0 |
| Пересечения 8 штифтов (74 поз.) | 0 |
| Соосность 8 шарниров (74 поз.) | макс. ошибка 3.78e-12; считалась по метаданным отверстий (центры/radii + трансформации кадра), без повторной экстракции цилиндров из STEP |
| Жёсткая связь серой P08 с тёмно-синей P07 | дрейф относительной матрицы 3.4e-11, две общие оси J7/J8 |
| Серая внутри жёлтой (74 поз.) | нет пересечений, минимальный запас габарита 6.69; **габаритная проверка (bounding box + отсутствие пересечения тел), не строгая проверка внутреннего контура/полости жёлтой** |
| Невырезанная P04 V3 ∩ новый P07 | 1061.559 усл.ед.³ (необходимость выреза) |
| Вырез в кандидате P04 | удалено 1061.559 усл.ед.³ — ровно объём пересечения (отн. 8e-13), после выреза пересечение = 0 |
| Сохранение: 7 деталей, слой P06/P07, посадка жёлтой, П-образный чёрный корпус | совпадает с V3 |

Вывод по P04: изменение посадки зелёной **необходимо и минимально** — новый
язык P07 пересекает посадочное место V3 в области
x∈[770.165, 777.287], y∈[−499.775, −471.940], z∈[−29.041, 27.0] (усл.ед.),
и кандидат удаляет ровно этот объём. Произвольных изменений остальных деталей
нет: 7 из 9 деталей побайтово равны V3.

## Границы

Масштаб референсного изображения не откалиброван, физические миллиметры не
установлены; регистрация красного скриншота приблизительна (~0.56 пикс). Проверка
пересечений дискретная (74 положения) и не доказывает отсутствия касаний между
отсчётами. Проверка «серая внутри жёлтой» — габаритная (bounding box + отсутствие
пересечения тел), не строгая проверка внутреннего контура или полости жёлтой.
Соосность вычислялась по метаданным отверстий (центры/radii + трансформации
положений), а не повторной экстракцией цилиндров из STEP. Прочность, жёсткость,
люфты, производственные допуски и производственная готовность не рассчитывались.
Способ фиксации осей в материале не назначен. Разрез корпусов во viewer/GIF меняет
только отображение.
