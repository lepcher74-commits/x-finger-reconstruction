# Сохранённая V6.4

Подтверждённая пользователем резервная копия: 129 файлов, 37 095 900 байт ZIP. Внутри: V6.1, восстановленная V6.3 и V6.4; STEP/STL, исходники, рисунок, просмотрщики, анимации и отчёты.

Архив разделён на пять бинарных частей из-за ограничения размера запроса. Скачайте эту ветку через Code → Download ZIP, распакуйте её, затем выполните `python restore.py` в этой папке. Скрипт проверяет Git SHA-1 каждой части, собирает X_Finger_V64_review.zip, проверяет CRC всех файлов и выводит SHA-256 архива.

V6.4 замыкает синюю чашу на зелёную опору с обеих сторон. Проверка движения дискретная (74 положения); физический масштаб, толщина 1,5 мм и производственные крепления ещё не подтверждены. Основная ветка не изменена.
